The `arachne prep` command sorts your input FASTQ files by barcode and outputs them in [standard format](https://blinkseq.github.io/lastq/),
which is necessary for `arachne align`. If already in this format (standard format + sorted by barcode), you can skip this step.
Read pairs with invalid or missing barcodes will **not** be discarded; the aligner will still align them with `minibwa`,
but won't post-process the alignments. Data format is automatically recognized, except in the case of 10X.

Formats recognized:
- 10X ([see below](#bc-list))
- haplotagging
- standard
- stLFR
- TELL-seq

```bash title="Usage"
arachne prep [options] PREFIX FORWARD_FASTQ REVERSE_FASTQ
```
This will create `PREFIX.arachne.R1.fq.gz`, `PREFIX.arachne.R2.fq.gz`.

```bash title="Example"
arachne prep -t 6 sample1 sample1.R1.fq.gz sample1.R2.fq.gz
```

## Arguments
| argument                   | default | description                                  |
| :------------------------- |:-------:|:-------------------------------------------- |
| `-b` `--bc-list string`    |         | Valid barcode list (10X Genomics input only) |
| `-t` `--threads int`       |    2    | Threads to use                               |
| `-p` `--tmp-prefix string` |         | Folder for temporary files                   |


### --bc-list
If the input data is from [10X Genomics](https://blinkseq.github.io/linkedreads/info/#10x-genomics), that is, barcodes inline with the R1 sequence, you must
include a "barcode whitelist" so arachne can recognize and validate the barcodes. The standard 10X
linked-read barcodes (`4M-with-alts-february-2016.txt`) are embedded into `arachne prep`, so
if your data uses the standard barcodes, you can write `-b 10x` to use the embedded list. Otherwise,
include your custom barcode list.

```bash title="Example: 10X input with default barcode list"
arachne prep -t 6 -b 10x sample1 sample1.R1.fq.gz sample1.R2.fq.gz
```

### --tmp-prefix
Sorting is done with a k-way merge like the kind done by samtools. This process generates a handful
of intermediate file chunks before merging them. Using `--tmp-prefix` makes sure there is no unexpected
filename clashing during this process, especially if multiple instances of `arachne prep` are being run
in parallel.
